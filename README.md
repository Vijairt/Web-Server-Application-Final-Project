# SOMA Fan Site

An ASP.NET Core MVC website (.NET 10) documenting one of my favorite hobbies: the horror video game **SOMA**.

SOMA is set in 2104 in PATHOS-II, an isolated, decaying underwater research station. It is a game of stealth, puzzle-solving and existential horror about AI, identity and consciousness.

## Pages

- Home
- About SOMA (`/Home/AboutGame`)
- Why It's Different (`/Home/WhyDifferent`)
- Privacy

## Tech

- ASP.NET Core MVC, .NET 10
- Bootstrap and jQuery (in `wwwroot/lib`)
- Entity Framework Core with SQL Server LocalDB (planned)

## Run

```
dotnet run --project "Web Server Application Final Project"
```

Or open `Web Server Application Final Project.slnx` in Visual Studio and press F5.
